# FE 및 UI 기능 명세서

## 1. 개요
- 문서 목적: 프로젝트 기능 계획 및 화면 구성, 상호작용 정의

## 3. 화면 별 기능 명세
### 3-1. apps/web
- 로그인(가능한 경우)
    - 상단 바에 로그인 버튼 구비(PC)
    - 햄버거 버튼 메뉴 밑에 로그인 버튼 구비(모바일)

#### 3-1-1. 홈
*/*
- 왼(PC): 소유자 정보, 게시글 목록
- 가운데: 소유자 정보(모바일), 게시글 목록
- 오(PC): 카테고리 목차

#### 3-1-2. 게시글
*/posts/:postId*
- 왼(PC): 소유자 정보, 게시글 목록
- 가운데: 게시글 제목, 게시글 목차(모바일), 게시글 내용, 댓글 입력(로그인 구현 시), 댓글(로그인 구현 시)
- 오(PC): 게시글 목차

### 3-2. apps/owner
*미확정*

#### 3-2-1. 홈
*/*
디자인 미정
현재: 게시물 작성 및 수정 삭제 가능하도록 잡을 예정.
인증되지 않을 시 /login 리다이렉트.

#### 3-2-2. 인증
*/login*
GitHub OAuth로 소유자 계정이 아니라면 캐시에 남긴 후 apps/web의 /으로 리다이렉트.
인증되었다면 다시 /으로.

#### 3-2-3. 게시글 작성
*/posting*
디자인 미정
가운데에 마크다운 형식으로 적을 수 있도록 textarea 마련.

#### 3-2-4. 게시글 수정
*/edit/:postId*
디자인 미정
원 마크다운 가져오기 -> 수정 가능하도록 textarea 마련.
